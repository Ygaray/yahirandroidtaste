# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Scope note (read first)

This phase is a **byte-faithful restore from git tag `v1.13.0`**, not new UI design (CONTEXT.md D-01,
confirmed with peers AccentColorPicker/IconPickerGrid). This UI-SPEC does **not** propose new visual
designs for `DateTimePicker`, `PlaceMapPicker` (+ cluster), or `PresetChip` — their layout, spacing,
color usage, and copy are fixed by the restored `v1.13.0` source and MUST NOT change (RESEARCH.md
Anti-Patterns: "Editing the ported component/model/test files' logic … treated as scope creep").
The contract below exists to (a) confirm the restored files' existing visual/interaction contract
resolves cleanly against `main`'s current tokens (it does — verified byte-identical below), and
(b) specify the one genuinely new presentation surface this phase adds: the 3 new
`ExplorerActivity` gallery entries (Pickers family: `DateTimePicker`, `PlaceMapPicker`; Chips
family: `PresetChip`) and the live on-device `MapView` preview behavior (D-03). The FilterBar
vs. ChipBar consolidation is not reopened (REQUIREMENTS.md Out-of-Scope; ChipBar stays canonical).

## Color

Material3 dynamic-role token system (`theme/Color.kt` — Teal primary / Slate secondary / Amber
tertiary / Error red, light+dark variants), not a fixed hex 60/30/10 palette. Restored composables
consume only `MaterialTheme.colorScheme.*` role references already defined on `main` — no new
color constant is introduced.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `MaterialTheme.colorScheme.surface` / `background` | Gallery scaffold background; `PlaceMapPicker`'s overlay-caption background (`surface.copy(alpha = 0.85f)`) |
| Secondary (30%) | `MaterialTheme.colorScheme.surfaceVariant` | `PlaceMapPicker`'s Compose-inspection-mode placeholder box (`_map_placeholder`, only rendered under `LocalInspectionMode` — never in the real on-device gallery run, see D-03 note below) |
| Accent (10%) | `MaterialTheme.colorScheme.primary` / `onSurfaceVariant` | `DateTimePicker`'s selected date/time affordance (existing Material3 dialog default); radius-row min/max captions (`onSurfaceVariant`) |
| Destructive | `ErrorRed` (`0xFFBA1A1A` light / `0xFFFFB4AB` dark) | Not exercised by any of the 3 ported composables — no destructive action exists in this trio; carried for completeness only |

Accent reserved for: the Material3 dialog's own selected-state indicator inside `DateTimePicker`
(unchanged from `v1.13.0`), and `PresetChip`'s `isSelected` container-color treatment (existing
`AppChip`-family selected-state convention) — no new accent usage is introduced by this phase.
