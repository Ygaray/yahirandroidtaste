<objective>
Enrich `VoiceOutcomeUiState.Failure` additively (VFAIL-01..03): the action button gets a
caller-chosen role (`FailureActionUiModel.role`, default Neutral), the error surface gets an
optional composable `body` slot, and the surface's accessibility announcement gets an optional
`semanticsPrefix` (D-02: a combined contentDescription on the surface's merged node).

Both classes are shipped `data class`es, and appending a field to one is NOT additive to Metalava by
default (Phase 15's critical finding: naive appends produce `RemovedMethod` errors on the
constructor and `copy`). The recipe proven in Phase 15 and reproduced green again in this phase's
research is `@JvmOverloads constructor` plus a hand-written old-arity `copy` that delegates to the
generated full-arity copy. Task 1 is the tracer: the whole recipe on the smallest model
(`FailureActionUiModel.role`) through every layer — model, FailureBody render wiring, JVM +
source-contract tests, `apiCheck`, `apiDump`, lane-3 commit. Task 2 repeats it for `Failure`
(`body` + `semanticsPrefix`) and adds the Compose tests for the slot, the prefix semantics and the
three roles.

Purpose: SecondBrain (SB-175) can mark a failure action destructive/save, show extra failure
detail inside the error surface, and announce a localized prefix, with zero change for callers that
pass none of it. Output: two re-shaped data classes (additive), FailureBody reading the new fields,
new JVM + Compose + source-contract tests, two regenerated api.txt commits.
</objective>
