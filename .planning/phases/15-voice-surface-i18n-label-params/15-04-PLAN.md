ApproachLadderCard.kt (313 lines) has these private pieces:
- RungRow(rung, isEffective, needsNetwork, isCapped, isSelected, unavailableLabel, cappedLabel, needsNetworkLabel, onCapClick, modifier). It calls CapControl and passes a RowScope content lambda: the name Text (maxLines 1, Ellipsis, Modifier.weight(1f)), then up to three conditional affordance Texts (labelSmall, onSurfaceVariant, no maxLines). The needs-network Text also has Modifier.padding(start = Dimens.ContentSpacing).
- CapControl(onClick, selected, modifier, content: RowScope.() -> Unit) is a Row with CenterVertically and spacedBy(4.dp). It sets semantics(mergeDescendants = true) and, only when onClick is non-null, selectable(Role.RadioButton) plus minimumInteractiveComponentSize. This is the D-03 swap seam from Phase 10: do not change its signature.
- Both toggles are SegmentedOptionSelector instances, tagged approach_ladder_card_offline_toggle and approach_ladder_card_router_toggle.

SegmentedOptionSelector.kt (public, 89 lines): a Column wrapping a SingleChoiceSegmentedButtonRow(Modifier.fillMaxWidth()). Each SegmentedButton has a semantics contentDescription of "$label, selected" or "$label, not selected". Its label is a Text with labelLarge, maxLines 1 and Ellipsis.

M3 version: material3 1.4.0 (Compose BOM 2026.04.01).
- SingleChoiceSegmentedButtonRow puts the caller modifier first, then selectableGroup, defaultMinSize(minHeight = 40.dp) and width(IntrinsicSize.Min). It does not equalize segment heights.
- SegmentedButton puts the caller modifier first, then weight(1f), defaultMinSize and the radio role. Its content goes through SegmentedButtonContentMeasurePolicy, which measures the icon AND the label with the incoming constraints unchanged, then places the label at x = IconSize (18dp) + IconSpacing (8dp) + offset. The offset is 0 when the check icon shows and -(IconSize + IconSpacing)/2 when it does not.
- Result: a label that fills its segment overflows the right edge by up to 26dp on the selected segment. This is the clipping root cause. Raising maxLines alone does NOT fix it.

Dimens: HorizontalPadding = 16.dp, ContentSpacing = 4.dp, HairlineSpacing = 2.dp.
FlowRow precedent in this repo: ChipBar.kt and AccentColorPicker.kt use androidx.compose.foundation.layout.FlowRow with @OptIn(ExperimentalLayoutApi::class).

Test harness precedent: ApproachLadderCardTest uses @RunWith(RobolectricTestRunner::class), @Config(sdk = [35]) and createComposeRule(). No test in the repo sets qualifiers or GraphicsMode yet. Robolectric is 4.16.1, and its default window is about 320dp wide.
- Rung rows merge their descendants. A rung's name or affordance Text node is therefore only reachable with useUnmergedTree = true.
- SemanticsNode.boundsInRoot is CLIPPED to ancestors, so it cannot detect overflow. Use fetchSemanticsNode().positionInRoot plus .size (unclipped layout geometry) or SemanticsNodeInteraction.getUnclippedBoundsInRoot().
- Line count: invoke the node's SemanticsActions.GetTextLayoutResult action into a mutable list and read the single TextLayoutResult (lineCount, isLineEllipsized(0)).
