<objective>
Make the three settings/voice-surface composables' hardcoded English labels caller-overridable via
optional defaulted `String` parameters (VI18N-01/02/03) — `ProviderKeyCard.providerLabel`,
`ModelSelectCard.modelLabel`, `ClarificationBar.dismissLabel`, and `ApproachLadderCard`'s five
`unavailableLabel` / `cappedLabel` / `needsNetworkLabel` / `onlineLabel` / `offlineOnlyLabel` — with the
English defaults preserved verbatim and the hub localizing nothing (INV-01). Per D-01 every new
parameter is appended LAST and Metalava `apiCheck` is the authoritative additive gate; each source
change ships with a freshly regenerated `api.txt` in the same commit under `HUB_LANE_OVERRIDE=3`.

This plan leads with a tracer (Task 1): `ProviderKeyCard.providerLabel` wired end-to-end — test, public
param, private-helper threading, `apiCheck` → `apiDump` → lane-3 commit — which proves the whole
guard flow once on the simplest target. Tasks 2-3 expand the identical pattern to the remaining three
composables. The four `OutcomeSheet`-embedded literals (VI18N-04) are model fields and belong to plans
15-02 / 15-03.

Purpose: a consumer (SecondBrain) can pass localized dropdown / dismiss / rung-state / toggle labels
without any behavior change for callers that pass none of them.
Output: four re-signatured public composables, new override + default-pin tests in the four existing
component test classes, regenerated `api.txt` (3 commits), a green full suite + detekt + apiCheck.
</objective>
