## Info

### IN-01: Consumer identifier disagrees between the two consumer tables in the same doc

**File:** `ECOSYSTEM.md:34,48`
**Issue:** The pre-existing human-authored table (line 34) names the consumer `CalTracker`, while
the new machine-reconciled matrix (line 48) names it `CalTracker_Android`. This is expected
behavior of `repin_status.py` — `_consumer_name()` derives the identifier from the literal
directory name under `~/Projects` (`~/Projects/CalTracker_Android`), and `_consumers_match()`
already fuzzy-matches `CalTracker` as a prefix of `CalTracker_Android` for drift validation, so
nothing breaks mechanically. But a future reader (human or agent) skimming both tables in the same
document could reasonably wonder whether these are two different consumers, since nothing in the
new section explains the naming source.
**Fix:** Add a short clause to the new blockquote, e.g.: "Consumer names here are the literal
`~/Projects/<dir>` checkout name (e.g. `CalTracker_Android`), which may differ from the short name
used in the table above (`CalTracker`)."

### IN-02: New matrix section doesn't cross-reference its relationship to the table directly above it

**File:** `ECOSYSTEM.md:40-50`
**Issue:** The document now has two consumer-pin tables back to back in §1: the original
hand-maintained table (lines 31–34, with narrative/provenance columns) and the new
machine-reconciled matrix (lines 45–50, with `Latest`/`Status` columns `reconcile` derives from
live tags). Nothing in the new subsection tells a reader why both exist or which one to trust when
they eventually disagree — that context currently lives only in the external
`~/.claude/context/workflows/repin.md`, not in this file. Per that workflow doc, `reconcile`
"never [touches] the narrative," so the two tables can drift apart over time (e.g., if the
top table's "Pins hub at" cell isn't updated in some future repin, or if `Latest`/`Status` change
between manual runs) with no in-document explanation of that possibility.
**Fix:** A one-line addition to the new blockquote or to the top table's existing footnote (line
36-38) pointing at the other, e.g.: "This matrix is a script-verified supplement to the table
above — it is regenerated automatically and does not update the narrative provenance columns
there."
