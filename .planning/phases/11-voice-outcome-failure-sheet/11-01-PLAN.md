<objective>
Deliver the prop-driven, domain-neutral outcome/failure sheet for the Voice Command family:
`OutcomeSheet` renders a `VoiceOutcomeUiState` (`Success` | `Failure`, sealed — a `NeedsConfirmation`
third arm lands purely additively in Phase 12, per D-02, and must not be guessed at here), a
"handled by: tier/approach" provenance indicator (D-04), a loud, error-role failure surface with an
optional action slot that the library never defaults on its own (D-08), and a generic undo
affordance — "Undo all (N)" + per-item rows with an `Unavailable` state and a loud `Refused`
substate (VUNDO-01, D-01/D-02) — built as a brand-new presentational projection that never touches
`UndoHistoryEntry`'s frozen `internal` constructor (Pitfall 2 / the `TagChipUiModel` ABI lesson).

This plan also folds in two CONTEXT.md decisions that refine the `Success` arm without their own
requirement ID: D-05 (a committed-but-editable Success carrying a consumer-injected editor slot)
and D-06 (batch per-row result reporting + an in-flight lock signal).

**Flagged assumptions (specless-probe fallback, not re-opened — see 11-CONTEXT.md/11-RESEARCH.md):**
VOUT-01 (domain-neutral rendering, no app nouns) is resolved by the phase boundary + D-02/D-04/D-05/
D-08 with no additional edge case needed beyond the sealed-state shape below. VOUT-02 ("handled by"
indicator) is resolved by D-04 (tier required, everything else optional). VOUT-03 (loud failure) is
resolved by D-08 (optional action slot) + Claude's Discretion (error/errorContainer roles, never
`AttentionCue`).

**Canon-referral breadcrumb (prohibition-probe Stage 2, phase-wide):** "never log a prop value"
is canon OWASP Information-Disclosure guidance — already covered by this plan's own `<threat_model>`
(T-11-01) and by 11-RESEARCH.md/11-VALIDATION.md's Security Domain table; not separately minted as
a `must_haves.prohibitions` item here.

Purpose: SecondBrain and CalTracker need one domain-neutral way to show "what happened" after a
voice command — success, failure, provenance, and undo — without either app authoring its own
sheet or the library knowing either app's nouns (INV-01).
Output: `VoiceOutcomeUiState` + five satellite models + `OutcomeSheet`, registered in the Voice
Command family, widened naming allowlist, passing Compose tests.

|----------|-------------|
| Consumer app -> OutcomeSheet props | The consumer supplies arbitrary strings (summary/reason/handledBy fields/undo labels/refused reason) and callbacks (action.onClick, onUndoAll, row onUndo); the library renders them as-is and never executes, persists, or interprets them (INV-01) |
