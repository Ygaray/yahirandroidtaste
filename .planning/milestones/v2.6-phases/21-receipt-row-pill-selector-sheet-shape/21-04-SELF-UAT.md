## Notes / anomalies (for the Gate-2 reviewer)

1. **Gallery Default cell measures 90.3 dp, not 92 dp (advisory, not a criterion failure).** The component is correct: with a plain `Text` in `supportingContent` the row is 92.4 dp on device (probe R1), exactly what ROADMAP SC1 and `ReceiptRowTest` claim. But `CardsFamilyScreen.kt`'s `ReceiptRowSupportingLine()` passes `style = MaterialTheme.typography.bodySmall` explicitly. M3 `Text(style = ...)` replaces `LocalTextStyle` rather than merging with it, so it drops the `ProvideTextStyle(bodySmall.receiptRowLine())` that gives the line `LineHeightStyle(Center, None)`; that one line is then 13.9 dp instead of 16 dp and every row built from the gallery's fixture is 90.3 dp (the whole Default States cell; by the same arithmetic the Variants cue row would be about 118.3 dp rather than 120, not measured). The same footgun applies to any consumer that passes an explicit `style` in the slot. Two cheap follow-ups for the owner (Phase 24 docs or a small gap, not a blocker for this gate): (a) change the gallery fixture to a plain `Text("Supporting line")`, and (b) add one KDoc sentence on `supportingContent` ("a Text that sets its own `style` replaces the row's line-height normalization; omit `style`"). The Robolectric 92 dp test uses a plain `Text`, which is why it could not see this.
2. **Samsung S Pen floating pen button.** A grey circular pencil icon appears at the right edge in the middle of many screenshots (e.g. beside the Disabled cell, beside P7). It is a system overlay (it also shows on the harness probe screen, which has no such element), not a ReceiptRow trailing action or a gallery FAB.
