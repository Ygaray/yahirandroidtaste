<objective>
Make the caller's user agent actually reach the OSM tile server, and make a blocked agent loud. osmdroid 6.1.20's MAPNIK source normalizes the agent to `<packageName>/<versionCode>` and ignores `userAgentValue`, so today's assignment in `configureOsmdroid` has no effect on the wire (a `com.example.*` host is blocked). `TileDownloader` applies `additionalHttpRequestProperties` with `setRequestProperty` AFTER the normalized header, so a `User-Agent` entry there wins.

Purpose: POL-03 (ROADMAP Phase 28 success criterion 5, first three bullets and the host probe), CONTEXT Runtime Decisions "POL-03 added", "scope change" and "load() detail" (binding). Plan 28-02 owns the placeholder-tile purge and the wire-level cache tooling.
Output: the header injection after every `load()`, an honest fallback and one `Log.w`, the KDoc ask, a hub-owned Explorer agent, and a one-tile host probe script. No public API change.

Runtime decisions recorded by this plan (UNATTENDED run, source ai-auto, each reversible, all inside the locked Runtime Decisions):
- PD-1 [header key]: the literal key `User-Agent`, the key SecondBrain already uses (CONTEXT: "Use the same header and key"), held in one private constant; `Configuration.userAgentHttpHeader` is not consulted.
- PD-2 [duplicates]: case variants of the key are removed before the put, so "exactly one User-Agent entry" holds even if a consumer persisted a differently cased key; other persisted request properties are kept.
- PD-3 [control characters]: ISO control characters are removed from the caller agent before trimming (CR or LF would otherwise reach `setRequestProperty` on a downloader thread). Internal hardening, not a behavior the requirements forbid.
- PD-4 [fallback]: `<packageName>/<versionName> (Android <Build.VERSION.RELEASE>)`, matching the probed examples such as `(Android 15)`.
- PD-5 [Log.w]: one line per `configureOsmdroid` call (a picker instance creates one MapView, so this is rare), no per-process de-duplication, tag `YatOsmdroid`.
- PD-6 [Explorer agent]: the probed real agent `YahirAndroidTasteExplorer/2.8 (+https://github.com/Ygaray/yahirandroidtaste)` as a static constant (the library has no BuildConfig), kept in `PickersFamilyScreen.kt`.
