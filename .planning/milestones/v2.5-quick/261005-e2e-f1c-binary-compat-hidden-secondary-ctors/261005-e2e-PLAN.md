MASK SEMANTICS (compiler contract). Default ctor: bit i set means value param i took its default; the caller
passes null (reference) or zero/false (primitive) in that slot, and the marker is null. copy$default: static,
receiver first (not counted), bit i refers to copy value param i, and a set bit means "use this.<prop>".
Consequence: every REFERENCE-typed copy$default shim parameter must be declared nullable, even `tier`,
because a v2.4 caller passes null in each defaulted slot, and a non-null Kotlin parameter gets an entry
null-check that throws. Primitive slots stay primitive (`amended: Boolean`). A ctor shim may keep v2.4.1's
exact Kotlin types, because required params are never defaulted. A `@Composable () -> Unit` slot lowers to
`Function2` under the Compose plugin, which matches the baseline.
