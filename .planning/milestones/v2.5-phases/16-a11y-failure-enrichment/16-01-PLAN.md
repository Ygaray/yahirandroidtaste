<objective>
Make the `ApproachLadderCard` rung rows meet the accessibility bar (VA11Y-01): the rung the user
chose as the cap is announced as the selected radio button (D-01), the other rungs are radio
buttons that are not selected, a cap-less ladder announces nothing of the sort (D-03), and every
interactive rung presents at least the minimum interactive touch size (D-04). Strictly internal and
semantics-only: no public signature changes, so `api.txt` does not move.

Task 1 is the tracer: the `rung.id == maxTierId` derivation threaded through the private
`RungRow` into the single seam `CapControl`, where the existing click modifier becomes
`selectable(selected, role = Role.RadioButton)`, proven end to end by Compose semantics assertions
(selected / role / cap-less negative / stale id). Task 2 expands with the minimum interactive size
on the interactive wrapper, proven by a falsifiable touch-bounds non-overlap test and a cap-less
no-inflation pin.

Purpose: TalkBack and other services can tell which tier the user capped at and treat the rungs as
a single-choice group; touch targets stop overlapping. Output: `ApproachLadderCard.kt` with the
private semantics + min-size seam, `ApproachLadderCardTest.kt` with the new assertions, two
lane-3 commits (no api.txt change).
</objective>
